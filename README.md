(EN)

HelpOn is the ticket management system for the fictional airline FlightOn. The platform centralizes the entire lifecycle of passenger/user requests—from registration to closure—covering critical areas such as baggage, refunds, special assistance, etc. The system features customized workflows for three distinct user profiles (Passenger, Agent, and Administrator), ensuring specific permissions and views tailored to each role’s needs. Technologies used: AngularJS, HTML5, CSS3, JavaScript, and a database implemented on Supabase.

(PT)

HelpOn é o sistema de gestão de chamados da companhia aérea fictícia FlightOn.
A plataforma centraliza todo o ciclo de vida das solicitações dos passageiros/usuários — desde o registro até o arquivamento — abrangendo áreas críticas como bagagens,
reembolsos, assistência especial etc. O sistema conta com fluxos personalizados para três perfis distintos (Passageiro, Atendente e Administrador), garantindo permissões
e visões específicas para cada necessidade. Tecnologias utilizadas: AngularJS, HTML5, CSS3, JavaScript e a implementação do Banco de Dados no Supabase.
